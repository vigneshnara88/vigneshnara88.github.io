Rule-guided code switching

Exploring generation and review workflows for realistic multilingual text, with explicit linguistic constraints.

Area
Data science
Methods & tools
Language rules · Agents · Annotation
View code on GitHub ↗

Motivation

Multilingual speakers move between languages in ways that depend on grammar, context and community. This project explores how explicit rules and iterative generation/review can support code-switched text, rather than treating language mixing as random word substitution.

Available implementation

English–Tamil and Malay–English packages organise language guidance, meaning preservation, annotation conventions, example provenance and review procedures. The packages include executable validation and benchmark-audit utilities.

The broader generation workflow pairs drafting with rule-based review. Speaker evaluation is needed to establish naturalness, semantic fidelity and whether generated material is useful for a downstream task.

Longer-term questions

Potential directions include language documentation, cross-linguistic comparison and multilingual speech technology. These are research directions, not established evidence that synthetic text preserves a community's linguistic conventions.

The work was influenced by internship experience. Any release of broader training materials depends on their provenance and ownership.
