SwitchF1

A self-developed ASR evaluation tool, motivated by the agentic code-switching project, for measuring language-switch preservation.

Area
Data science
Methods & tools

Why I built it

I developed SwitchF1 while working on agentic code-switching generation. I wanted to assess whether a speech-recognition model preserved a speaker's switches between languages, as well as whether it recognised individual words correctly.

Ordinary word error rate counts substitutions, deletions and insertions. It does not directly isolate whether a language switch was preserved, missed or invented. SwitchF1 adds that focused view by comparing a reference transcript with the model's prediction, using explicit token-language labels and text alignment.

Familiar F1 mathematics, a specific evaluation task

The mathematics follows ordinary precision, recall and F1. A correctly matched directed switch is a true positive; an extra predicted switch is a false positive; a missed reference switch is a false negative. Precision = TP / (TP + FP), recall = TP / (TP + FN), and F1 = 2TP / (2TP + FP + FN).

My contribution is the implementation and the definition of how switch events are aligned, matched and counted in this setting. It applies the familiar scoring framework to the gap I encountered in code-switched ASR evaluation, rather than introducing a new F1 formula.

The implementation

The public repository includes a versioned scoring specification, Python API and command-line interface, worked examples, adversarial scenarios and tests. Explicit language labels allow the method to address languages that share a script.

Interpretation

For ASR evaluation, the reference words and language labels should be checked against the speech, and predicted labels should be obtained independently. The score measures switch preservation in the resulting text; without timestamps it does not establish the exact moment of a switch in the audio.

SwitchF1 complements WER and CER. A model can preserve the language transition while still transcribing the surrounding words incorrectly. When there are no reference or predicted switches, the switching F1 is undefined rather than automatically perfect.
