Research proposal

Pé-de-Meia: schooling and work

When financial incentives keep adolescents in school, how do their work choices change?

Area
Developing research
Methods & tools
Python · Policy evaluation
View code on GitHub ↗

The question

A schooling incentive can lead adolescents to leave work, reduce hours, change jobs, combine school and work, or return to education from neither activity. These responses can produce similar schooling outcomes while implying very different changes in the burden of work.

Proposed data and design

The proposal centres on PNAD Contínua, with administrative schooling, payment and formal-employment sources as complements. The baseline compares changes for adolescents predicted to be eligible with those in a nearby income band, using a difference-in-differences and event-study framework.

The code supports explicit sample construction and design preparation. The planned sample avoids conditioning on current enrolment, because schooling is itself an outcome.

What needs to be identified

Survey income is not the administrative income measure used to assign benefits, and predicted eligibility is not observed receipt. The proposal therefore targets a reduced-form comparison, with attention to rollout timing, comparison-band choices and household income excluding the adolescent's own earnings.

This is a research proposal. The portfolio does not present completed programme-effect estimates.
