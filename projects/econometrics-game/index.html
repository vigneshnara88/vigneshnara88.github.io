Econometrics Game

Applying empirical methods to education and fertility questions under competition time constraints.

Area
Selected research
Methods & tools
Python · Stata · Causal inference
View code on GitHub ↗

Two empirical settings

The preliminary-round work studies heterogeneous responses to performance-based financial aid. The final-round work examines whether the 2010 OxyContin reformulation changed fertility more in states with greater baseline exposure.

Methods

The education analysis uses random assignment as an instrument for programme participation, with subgroup first-stage and outcome comparisons. The fertility analysis uses a continuous-exposure difference-in-differences design, state and year fixed effects, and event-study analysis.

The source materials include Python data-building and analysis scripts, Stata specifications, and saved tables and figures.

Teamwork

Our team placed second. This is joint competition work; the project should be read as a team contribution rather than a claim of sole authorship. The central learning was turning an unfamiliar question into a defensible empirical workflow under time constraints.
